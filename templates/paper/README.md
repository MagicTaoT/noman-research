# New paper checklist

Copy the structure into a new `papers/YYYY/<slug>/` directory; do not add a
placeholder paper to the public catalog. Replace every placeholder before release.

Required publication files:

- `README.md`: question, evidence level, authors, links, version, limits and release scope.
- `metadata.json`: identity, authorship, dates, status, license and included/excluded materials.
- `paper.md`: the complete approved manuscript with local figure links.
- `appendix.md`: the approved appendix, where applicable.
- `pdf/`: approved paper PDF(s), named with their versions.
- `figures/`: only the original figures used by the paper.
- `results/README.md`: units, evidence levels, aggregation and reproduction limitations.
- `results/tables.json`: exact string-valued exports of the paper's Markdown tables, if any.
- `citation.bib`: author, title, date, version, institution and stable public URL.
- `CHANGELOG.md`: substantive changes and corrections by version.
- `RELEASE_NOTES.md`: release contents, headline findings and limitations.
- `SHA256SUMS`: generated by the repository validator after review.

Translations may use language suffixes such as `.zh-CN.md`. Record whether they
are complete translations or summaries. Use metadata and the catalog to identify
the authoritative manuscript version and any deviations between languages.

Do not ship raw datasets or assume code is approved for publication. Follow
the repository publication guide and state the actual public scope.
